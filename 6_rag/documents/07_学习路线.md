# 星舟编程学堂：学习路线与环境准备

- 文档编号：XZ-007
- 生效日期：2026-09-01
- 说明：本文描述虚构平台，仅用于 RAG 练习。学习安排属于建议，不增加课程购买或证书领取条件。

## 一、按目标选择路线

| 学习目标 | 起点 | 建议顺序 |
| --- | --- | --- |
| 用 Python 处理日常文件 | 没有编程基础 | 学习 PY101，再用个人记账本项目练习 CSV 文件处理 |
| 完成表格分析和经营报告 | 没有编程基础 | 先学 PY101，再学 DA201，最后完成咖啡店月度经营分析项目 |
| 完成表格分析和经营报告 | 已掌握列表、字典、函数和文件读写 | 可直接学习 DA201，无需先取得 PY101 证书 |
| 制作个人作品展示站 | 能进行基本电脑操作 | 学习 WEB101，无需先学习 Python，也可与 PY101 并行 |

路线中的课程需要分别确认访问权限。学习顺序不代表打包销售，也不代表购买前一门课后自动获得后一门课。建议学时以《课程目录与先修要求》为准，套餐范围和价格以《价格与会员权益》为准。

## 二、每周学习安排

时间有限的学习者可以每周安排 6 小时：2 小时观看课程并记录问题，2 小时独立完成练习，2 小时复盘错误和推进项目。这是可调整的安排，不是平台规定的最低学习量。

估算所需周数时，用所选课程的建议总学时除以每周可用小时数；需要安排完整周时向上取整。这个估算不包括额外复习、项目返工和等待审核的时间，也不改变会员的有效期。

## 三、进入 DA201 前的自查

除列表、字典和函数外，学习者应确认自己已经掌握文件读写。可以用以下练习检查准备情况：

1. 从本地 CSV 文件读取记录，并说明每列的含义。
2. 用函数整理记录，将汇总结果写入一个新的 CSV 文件。
3. 在文件路径写错时读懂错误信息，并修正路径后重新运行。

这些练习用于自查，不是平台的入学考试，也不要求上传结果。没有 PY101 证书不影响具备同等基础的用户直接购买 DA201；还不会文件读写时，建议先补学相关章节。

## 四、环境准备清单

| 课程 | 开始练习前准备 | 注意事项 |
| --- | --- | --- |
| PY101 | 平台在线代码编辑器，或本地 Python 3.11 | 在线编辑器适合基础练习，不支持安装额外第三方库 |
| DA201 | 本地 Python 3.11、Jupyter Notebook 和课程要求的数据分析依赖 | 确认能读取本地 CSV、运行 Notebook 并保存结果，不能只依赖平台在线编辑器 |
| WEB101 | 本地文本编辑器和浏览器 | 建立项目文件夹，分别保存页面、样式、脚本和图片 |

项目需要提交哪些文件、如何命名和修改，见《课程项目提交指南》。环境准备完成不等于获得课程权限，项目练习完成也不等于自动满足证书条件。
