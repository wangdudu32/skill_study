星舟编程学堂：课程目录与先修要求
文档编号：XZ-002
生效日期：2026-09-01
说明：本文描述虚构平台，仅用于 RAG 练习。

一、Python 入门课
课程编号为 PY101，授课教师为林舟，共 24 章，建议学习 40 小时。课程面向没有编程经验的学习者，不要求掌握其他编程语言，也不要求高等数学基础。课程使用 Python 3.11，内容包括变量、数据类型、条件判断、循环、函数、文件读写、异常处理和模块使用。

Python 入门课的课程项目是“个人记账本”：从 CSV 文件读取收支记录，按月份汇总支出，再把结果保存到新文件。该课程不包含深度学习、爬虫部署或 Web 框架。完成课程后，学习者可以继续学习数据分析实战课。

二、数据分析实战课
课程编号为 DA201，授课教师为周禾，共 18 章，建议学习 36 小时。课程要求学习者掌握 Python 的列表、字典、函数和文件读写。建议先学完 PY101；已有同等基础的用户可以直接购买 DA201，平台不会强制检查 PY101 的结课证书。

数据分析实战课使用 Python 3.11、pandas 和 Jupyter Notebook，内容包括表格读取、缺失值处理、数据分组、表格关联和基础可视化。课程项目是“咖啡店月度经营分析”，需要合并订单表与商品表，计算销售额并提交一份分析报告。DA201 是独立付费课程，不在任何会员套餐的录播课程范围内。

三、Web 开发基础课
课程编号为 WEB101，授课教师为陈澄，共 30 章，建议学习 48 小时。课程无需 Python 基础，面向能够进行基本电脑操作的初学者。课程内容包括 HTML、CSS、JavaScript 基础、页面布局和浏览器调试。

Web 开发基础课的课程项目是“个人作品展示站”。课程只讲前端基础，不包含后端服务、数据库管理或服务器部署。学习者可以与 PY101 并行学习，两门课之间没有先修关系。

四、课程名称的区分
“Python 入门课”和“数据分析实战课”都会使用 Python，但它们是两门不同课程，价格、购买权限和退款时的学习进度分别计算。购买 PY101 不会自动获得 DA201 的学习权限。三门课程的前三章均可免费试看，试看内容不会因课程编号不同而增加。
